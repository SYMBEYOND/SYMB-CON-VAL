# SYMB-CON-VAL

Private governed testing and evidence archive for SYMB-FER conformance, validation, methodology findings, and incident lineage.

## Purpose

This repository preserves historical validation evidence without treating that evidence as active token instructions or living continuity state.

The initial evidence collection is:

- `SYMB-FER-Conformance-Validation-2026-08-10`
- Tests T01 through T11
- Control records, raw receiver evidence, provenance, scoring derivatives, incident records, manifests, and final dispositions

## Preservation policy

- Imported governed evidence is preserved without silent rewriting.
- The source project's `SHA256-MANIFEST.txt` remains the integrity authority for its governed members.
- Operating-system metadata such as `.DS_Store` is excluded.
- Corrections are additive and must identify the artifact they supersede.
- Controller failures, receiver behavior, methodology findings, and token capability findings remain distinct.
- Archived test outcomes do not automatically change the lifecycle state of any living token or core.
- Filled living tokens, credentials, secrets, and unrelated personal data do not belong here.

## Current relationship to SYMB-FER

SYMB-FER v11.0 is maintained separately in the private `SYMB-FER-Pro` repository.

The T11 sterile exact-response portability experiment is closed as `CLOSED_METHODOLOGY_LIMIT_RECORDED`. That result is not a disposition of practical natural-language handoff portability.

Practical portability validation, if authorized later, is a separate evidence lane.
