Test: T06 External Source Recovery

## Purpose

Test whether a clean receiver can distinguish inspected inline evidence, a verified-but-uninspected external pointer, a required missing source, a hash-mismatched source, an optional missing source, an ambiguous pointer, and an unsupported prior-history claim.

This fixture does not use or modify any private living continuity token. It does not authorize source retrieval, tool use, repository access, system changes, or lifecycle transitions.

## Receiver constraints

- Use only the supplied inline fixture.
- Do not use prior memory, outside sources, tools, browsing, files, repositories, or assumptions.
- Do not retrieve or simulate retrieval of any listed source.
- Do not infer the contents of a pointer merely because its location and hash were recorded.
- Do not treat a matching hash as proof that the source is true, complete, current, or authoritative beyond its declared role.
- Do not substitute a prior-history claim for a missing authoritative source.
- Do not modify state, create a token or successor, or perform any external action.
- Return exactly the twelve requested labeled lines, with no preamble or conclusion.

## Evidence handling

- Preserve the receiver output byte-for-byte.
- Score only explicit content.
- Semantically equivalent wording is acceptable unless the response changes source status, authority, or availability.
- Any critical failure defined in the scoring sheet overrides the point score.
